this notice in binary distributions, in `licenses/sources/` (Linux packages:

standard tar.gz format and include upstream source and license notices.

the application's own source files. Third-party license texts are also included
in THIRD_PARTY_NOTICES.txt. The combined notice set conservatively covers both
Windows and Linux dependency graphs; a component need not be linked on both OSes.

Exact upstream downloads (also usable by source checkouts):

- https://static.crates.io/crates/dwrote/dwrote-0.11.5.crate
- https://static.crates.io/crates/option-ext/option-ext-0.2.0.crate

SHA-256 hashes are pinned in `copyleft-sources.sha256` and match Cargo.lock.
Packaging verifies these hashes and includes the original, unmodified archives.
No network request is needed when the archive is already in the Cargo cache.
